    深度学习 = 人工神经网络 + 训练学习策略

    机器学习经典流程: 训练集、验证集、测试集。

    机器学习模型的若干性能度量指标来判断性能优劣。 对于二分类问题, 有如下参数。正例总数 \(P\), 负例总数 \(N\)。机器模型预测类别与实际类别的关系可以将用例分为四类: 真正例 \(TP\), 假正例 \(FP\), 真反例 \(TN\), 假反例 \(FN\)。

    • 准确率(\(Accuracy\)): \(Acc = \frac{TP+TN}{P+N}\)
    • 错误率(\(Error~Rate\)): \(ErrorRate = \frac{FP+FN}{P+N}\)
    • 精确率或者查准率(\(Precision\)): \(Precision = \frac{TP}{TP+FP}\)
    • 召回率或者查全率(\(Recall\)): \(Recall = \frac{TP}{TP+FN}\)

    赫布理论: 神经元之间持续重复经验刺激可以使突触传递效能增强。 前馈神经网络

    反向传播的主要步骤:

    • 前向传播: 网络接收输入并通过每一层的传递, 直到产生输出。每一层的输出都是下一层的输入, 每一层只会接受相邻的前一层的信号。
    • 计算误差: 在输出层, 计算神经网络的实际输出值与期望正确值之间的误差。常见的损失函数包括均方误差(传统均方差)以及交叉熵。
    • 反向传播误差: 将输出层的误差反向传递回网络, 通过计算神经网络输出值相对于各个权重的偏导数得到每一层每个神经元的误差贡献。
    • 更新权重: 根据误差贡献调整每个连接权重, 一般使用梯度下降的方式更新权重(更新量取决于步长、偏导数以及误差值)

    非线性映射的激活函数

    一般的线性映射难以满足使用神经网络来拟合任何函数的终极目标, 因此我们需要使用非线性激活函数在神经网络中掺入非线性成分。

    \(\mathrm{Sigmoid}\) 函数

    \(\mathrm{Sigmoid}\) 有点类似于高中生物学中的种群数量增长的 \(S\) 型曲线, 其解析表达式如下所示:

    \[ f_{sigmoid}(x) = \frac{1}{1+e^{-x}} \]

    在误差反向传递时我们往往需要需要计算各变量对于误差的贡献值, 自然也需要计算非线性激活函数的导数值, 表达式如下:

    \[f^{'}(x) = \frac{e^{-x}}{(1+e^{-x})^{2}} = \frac{1+e^{-x}-1}{(1+e^{-x})^{2}} = \frac{1}{1+e^{-x}}(1-\frac{1}{1+e^{-x}}) = f(x)(1-f(x))\]
    • \(\mathrm{Sigmoid}\) 函数的值域为 \((0, 1)\), 其输出值可以视为概率分布。
    • \(\mathrm{Sigmoid}\) 函数单调递增可以满足非线性激活函数最基本的要求。
    • \(\mathrm{Sigmoid}\) 函数在 \(0\) 处的灵敏度很高, 很容易被激活并发生非线性变化。
    • \(\mathrm{Sigmoid}\) 函数梯度中 \(f(x) < 1\) 且 \(1-f(x) < 1\), 故 \(f^{'}(x) = f(x) (1-f(x)) < 1\), 在曲线两端处梯度值尤其小。小于一的梯度在经过深层神经网络的多次反向传递后会趋于极小的值, 出现 \(Vanishing~Gradient\) 对于神经网络参数调整的作用被大幅削弱。 \(sigmoid\) 函数不适合深层网络, 因为其在两端处的梯度过小, 对于深层网络会出现 \(vanishing~gradient\) 梯度消失的情况。

    \(\mathrm{tanh}\) 函数

    \(\mathrm{tanh}\) 函数是双曲正切函数, 同一家族的还有双曲正弦函数 \(sinh(x)\) 以及双曲余弦函数 \(cosh(x)\), 各自表达式如下所示: $$ tanh(x) = \frac{1-e^{-2x}}{1+e^{-2x}}~~~~~sinh(x) = \frac{e^{x}-e^{-x}}{2}~~~~~~cosh(x) = \frac{e^{x}+e^{-x}}{2}$$ 在神经网络中使用双曲正切函数则是因为其将 \((-\infty, +\infty)\) 的数值压缩至 \((-1, 1)\) 区间内。

    • 相较于 \(\mathrm{Sigmoid}\) 函数, \(\mathrm{tanh}\) 函数在原点处的梯度更大。
    • 与 \(\mathrm{Sigmoid}\) 函数相同的是在深层神经网络中, \(\mathrm{tanh}\) 函数同样会发生梯度消失。

    \(\mathrm{ReLU}\) 函数

    \(\mathrm{ReLU}\) 函数(\(\mathrm{rectified~linear~unit}\) 修正线性单元)虽然没有上述两种函数自然且美观, 但是其是神经网络(尤其是深层神经网络)中最为常用的非线性激活函数, 表达式如下:

    \[ f_{ReLU}(x) = max(0, x) = \begin{cases} 0, & x < 0 \\ x, & x \geqslant 0 \end{cases} \]

    由此可以得到 \(\mathrm{ReLU}\) 函数的导数表达式:

    \[ f_{ReLU}^{'}(x) = \begin{cases} 0, & x < 0 \\ 1, & x \geqslant 0 \end{cases} \]
    • 当输入数据为非负数时, \(\mathrm{ReLU}\) 函数的导数为常数, 可以有效地避免上述两个函数的梯度消失问题。
    • 当输入数据为正数时, \(\mathrm{ReLU}\) 函数的导数为零, 使得神经网络中的若干参数值为零。参与分类等任务的神经元稀疏, 可以一定程度上避免机器学习中容易出现的过拟合问题。

    \(\mathrm{Softmax}\) 激活函数

    \(\mathrm{Softmax}\) 函数一般用在分类问题中, 亦称为多项逻辑斯蒂回归模型( \(\mathrm{multi-nominal~logistic~mode}\) )。假设要实现共 \(k\) 个类别的分类任务, 则深度学习模型一般最终会得到一个 \(k\) 维向量(\((x_{1}, x_{2} ···, x_{k})\)), 经过 \(\mathrm{Softmax}\) 函数的非线性映射得到如下所示向量:

    \[ y_{i} = Softmax(x_{i}) = \frac{e^{x_{i}}}{\Sigma_{i = 1}^{k}e^{x_{j}}} \]
    \[ (x_{1}, x_{2} ···, x_{k}) \rightarrow (y_{1}, y_{2} ···, y_{k}) \]
    • 可以发现, 经过 \(\mathrm{Softmax}\) 函数处理后的向量各分量之和为 \(1\), 该向量实际代表分类的结果在各个类别中可能的概率。
    • 我们通常选择概率值最大的分量对应的分类类别作为最终的分类结果。

    常见的损失函数

    损失函数(代价函数): 用于计算模型预测值与真实值之间的误差。根据损失函数来计算神经网络的误差大小, 进一步地通过反向传播和梯度下降对神经网络中的各个相关参数进行优化。常见损失函数包括 均方误差损失函数 以及 交叉熵损失函数。

    均方误差损失函数:

    均方差损失函数 \(\mathrm{Mean~Square~Error}\) 是传统的方差计算方法, 如果对于训练数据 \(x_{i}\), 模型预测值为 \(y_{i}\), 实际正确值为 \(\widehat{y_{i}}\), 则 \(n\) 次训练的均方差定义如下所示:

    \[ MSE = \frac{1}{n} \Sigma_{i = 1}^{n}(y_{i} - \widehat{y})^{2}\]

    交叉熵损失函数:

    交叉熵是信息论中的重要概念, 用于度量两个概率分布的之间的差异。对于我们经常研究的分类问题, 交叉熵是一个非常好的损失函数的计算方法。因为我们模型每次运行得到的结果就是一个 \(k\) 维向量, 表征的是待分类目标属于各个类别的潜在可能性, 这个 \(k\) 维向量 \((y_{1}, y_{2} ···, y_{k})\) 本身就是一个概率分布 \(q\)。与此同时我们还有实际的概率分布 \(p\), 后者的形势非常简单, 因为其本身是一个确定性事件而非不确定事件, 概率分布 \(q\) 的表征向量形如 \((\widehat{y_{1}}, \widehat{y_{2}}, ···, \widehat{y_{k}}) = (0, 0, ···, 1, ···, 0, 0 )\) 。因此一般形式的交叉熵又可以被进一步简化(此处讨论的是分类问题):

    \[ \begin{align*} H(p, q) &= -\Sigma_{i=1}^{n}(p(x)\times \log{q(x)}) \\ H(p, q) &= H(y_{i}, \widehat{y_{i}}) = -\widehat{y_{i}} \times \log{\widehat{y_{i}}} \end{align*} \]
    • 独热码: 对于一个数值的一串编码中只有一位是一, 其余为全部为零。(此处的实际概率分布就是独热码的形式)

    梯度下降算法的三种主要策略:

    • 批量梯度下降: 在整个训练集上计算损失误差 \(L(\theta)\), 如果数据集比较大则会因为内存容量不足而无法完成梯度计算。
    • 随机梯度下降: 使用数据集中每一个训练样本计算 \(L(\theta)\) 来分别更新参数, 随机性有助于跳出局部最优解; 随机梯度下降每次迭代只使用一个样本使得梯度方向以及梯度的数值具有很大的波动, 收敛的难度增强。
    • 小批量梯度下降: 选取训练集中小批量样本计算 \(L(\theta)\), 根据每一批样本所得的累加误差来更新参数, 可以保证训练过程稳定, 同时可以利用矩阵计算优势。小批量梯度下降是当前最为广泛使用的梯度下降的方法。

    卷积神经网络

    卷积可以从一个单元及其周围处提取出一个合并后的元素, 因此卷积神经网络是可以感受到方向和距离的。对于一张图片 \(H\times W\) 个像素点(竖直方向 \(H\) 个像素点, 水平方向 \(W\) 个像素点), 每一个像素点处是三通道(三原色红黄蓝的对应权重)(如果是黑白的图像则是单通道的即可)。通道的数量可以视为图像的厚度, 单通道的图像是一个平面矩阵, 多通道的图像则是一个体型结构。

    如果称一个“三维图像”有 \(\mathrm{X}\) 方向, \(\mathrm{Y}\) 方向以及\(\mathrm{Z}\) 方向。则我们通常的做法是对 \(\mathrm{X-Y}\) 平面进行压缩, 同时对 \(\mathrm{Z}\) 方向进行拉伸。即截面积减小, 但是深度在不断增长。前者需要通过下采样完成, 后者则是需要通过卷积核的设计完成。

    此处的 \(I\) 是卷积处理之前的图像, \(C\) 是通道数, \(\mathrm{H\times W}\) 是 \(X-Y\) 平面的度量。

    \[I \in \mathbb{R}^{C \times H \times W}\]

    现有一个卷积核 \(W \in \mathbb{R}^{3 \times 3 \times C^{'} \times C }\), 其中 \(3 \times 3\) 是卷积核在 \(X-Y\) 平面的度量, \(C^{'} \times C\) 则是表明该卷积核将会把深度为 \(C\) 的图像转化为深度为 \(C^{'}\) 的图像, 具体的转化如下:

    \[ \begin{align*} I^{'(x,y)} &= \Sigma_{i = -\lfloor \frac{h}{2} \rfloor}^{\lfloor\frac{h}{2} \rfloor} \Sigma_{j = -\lfloor\frac{h}{2} \rfloor}^{\lfloor \frac{h}{2} \rfloor} W^{(i,j)} \cdot I^{(x+i, y+j)}\\ &= \Sigma_{i = -1}^{1} \Sigma_{j = -1}^{1} W^{(i, j)} \cdot I^{(x+i, y+j)} \end{align*} \]

    全连接层的信号传递可以视为矩阵运算(线性变换) 多层感知机至少需要三层全连接层 卷积神经网路是可以感受到方向和距离的 卷积核没有偶数边的 卷积过程中边缘处补零的效果会更好 卷积核规模大: 会引入大量噪声, 会引入大量待定参数 \(\(I \in \mathbb{R}^{C \times H \times W}\)\)

    \[I^{'(x,y)} = \Sigma_{i = -\frac{h}{2}}^{\frac{h}{2}} \Sigma_{j = -\frac{h}{2}}^{\frac{h}{2}} W^{(i,j)} \cdot \]

    一般池化的策略是最大池化以及平均池化, 显然最小池化没有存在的意义
